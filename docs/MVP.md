# Discovery Run 01 MVP

The MVP proves one traceable path: lawful source query, metadata preservation,
allowed document download, immutable SHA-256 artifact, page, evidence span,
candidate card, human decision, and deterministic JSON/Markdown dossier.

It uses one live NASA NTRS/NACA adapter, one local fixture adapter, a CLI,
PostgreSQL, an immutable external CAS, and a PostgreSQL-backed job queue.

It excludes mass ingestion, browser UI, vector and graph databases,
uncontrolled crawling, automated legal conclusions, automatic prototype
generation, and operational handling of dangerous material.
