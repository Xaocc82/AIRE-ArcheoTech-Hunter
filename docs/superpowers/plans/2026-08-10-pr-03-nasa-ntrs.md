# PR-03 NASA NTRS Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development task-by-task.

**Goal:** Implement a bounded, read-only NASA NTRS metadata search adapter.

**Architecture:** The adapter POSTs a JSON query to NTRS's public citation-search endpoint through an injected transport. It filters NACA publication dates (1915–1950), caps result count using `SourceQuery.max_records`, and converts response records into the existing normalized source values. CI uses an in-memory transport; no live request is automatic.

**Tech Stack:** Python standard-library JSON and urllib request objects; pytest.

## Global Constraints

- Endpoint: `https://ntrs.nasa.gov/api/citations/search`.
- Public, read-only metadata only; no document downloads in this PR.
- Timeout and User-Agent are explicit; the adapter never retries automatically.
- Network tests are opt-in only.
